# YANSYN-E2EE

焰行端到端加密工具 —— 一个基于 Java Swing 的本地加密通讯软件。

## 简介

YANSYN-E2EE 是一款端到端加密（End-to-End Encryption）工具，用于安全地加密文本和文件。它使用 RSA + AES 混合加密方案，配合数字签名验证发送者身份，确保只有指定的收件人才能解密内容。

## 功能特性

- **文本加密/解密**：加密消息后生成 Base64 密文，可复制发送给对方
- **文件加密/解密**：支持任意格式文件，加密后生成 `.enc` 文件
- **密钥管理**：生成 RSA 2048 位密钥对，私钥用密码加密保存
- **好友管理**：导入好友公钥，建立通讯录
- **数字签名**：每条消息附带签名，解密时可验证发送者身份
- **免密码模式**：可选开启，启动时输一次密码后，后续操作不再重复输入
- **账户导入/导出**：把密钥和好友列表打包成 `.zip` 备份，方便换机
- **虚拟收件人**：用自己公钥创建虚拟收件人，用于测试加密功能

## 加密方案

- 对称加密：AES-256-CBC
- 非对称加密：RSA-2048（PKCS#1 Padding）
- 密钥派生：PBKDF2WithHmacSHA256（100000 次迭代）
- 签名算法：SHA256withRSA

## 运行环境

- 需要 Java 运行环境（JRE 8 或更高版本）
- 支持 Windows / macOS / Linux

## 使用方法

### 首次使用

1. 双击运行 `.jar` 文件（或命令行执行 `java -jar YANSYN-E2EE1.0.0.jar`）
2. 点击「生成密钥对」，设置一个保护密码
3. 点击「导出公钥」，把公钥发给你的朋友

### 添加好友

1. 拿到朋友的公钥文件（`.key` 或 `.pub`）
2. 点击「添加好友」，选择对方的公钥文件
3. 给好友起个名字，保存

### 加密文本

1. 在左侧选择收件人
2. 在「文本操作」标签页输入要发送的消息
3. 点击「加密文本」，复制生成的密文发给对方

### 解密文本

1. 把收到的密文粘贴到输入框
2. 点击「解密文本」
3. 下方会显示明文，同时显示签名验证结果

### 加密文件

1. 在左侧选择收件人
2. 切换到「文件操作」标签页
3. 点击「选择文件」，选中要加密的文件
4. 点击「加密文件」，保存生成的 `.enc` 文件
